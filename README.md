# منظومة ابن السنوسي لحلول الطاقة الشمسية والكهربائية (ERP & POS)
### Ibn Al-Sanusi Solar & Electrical Solutions ERP & Cashier System

نظام متكامل لإدارة المبيعات ونقاط البيع السريعة (POS)، المخزون وتتبع الأرقام التسلسلية (Serial Numbers)، الفواتير الرسمية بالورق المروس، العملاء، المشتريات والموردين، الموظفين، والتقارير التحليلية، مع ربط سحابي فوري بقاعدة بيانات **Supabase**.

---

## المميزات الرئيسية (Core Features)

1. **نقاط البيع السريعة (POS & Cashier):**
   - بيع فوري وسلس للعملاء النقديين (Walk-in) أو العملاء المسجلين.
   - حساب فوري للمبالغ والضرائب والخصومات.
   - خيارات دفع متعددة (نقداً، بنكك / تحويل بنكي، بطاقة مصرفية، بيع آجل).
   - خصم فوري ودقيق للمخزون وسحب الأرقام التسلسلية المباعة.

2. **الفاتورة الرسمية (الورق المروس الفاخر):**
   - تصميم مطابق للورق المروس المعتمد للشركات.
   - شعار الشركة، الرقم الضريبي، السجل التجاري، وبيانات الاتصال.
   - تفقيط المبالغ باللغة العربية (تحويل الأرقام إلى كلمات).
   - رمز التحقق الإلكتروني (QR Code).
   - أختام وتواقيع الشركة الرسمية وشروط الضمان.
   - جاهزة للإرسال والطباعة المباشرة إلى أي طابعة متصلة (A4 / طابعات حرارية).

3. **إدارة المخزون وتتبع السيريال (Inventory & Serial Tracking):**
   - تتبع دقيق لكل قطعة برقمها التسلسلي لمنع تكرار الأجهزة.
   - تنبيهات انخفاض المخزون والحد الأدنى للطلب.
   - توثيق لحظي لكل حركة مخزنية في سجل الحركات (`inventory_logs`).

4. **الربط السحابي (Supabase Cloud Database):**
   - مزامنة سحابية ثنائية الاتجاه للمنتجات، الفواتير، العملاء، الموردين، والموظفين.
   - مصادقة وأمان للمستخدمين والأدوار الوظيفية.

## التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS
- **Backend / Database:** Supabase (PostgreSQL, Auth, Realtime)
- **Tooling:** Vite, Node.js
